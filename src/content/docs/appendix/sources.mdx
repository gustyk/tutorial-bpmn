## Sumber primer

- [OMG BPMN 2.0.2 — halaman spesifikasi](https://www.omg.org/spec/BPMN/2.0.2/) — metadata normatif dan tautan dokumen.
- [OMG BPMN 2.0.2 — PDF](https://www.omg.org/spec/BPMN/2.0.2/PDF) — sumber normatif untuk semantics, grammar, dan conformance.
- [Camunda BPMN Reference](https://camunda.com/bpmn/reference/) — visual symbol reference dan praktik pemodelan.
- [Camunda 8.9 BPMN coverage](https://docs.camunda.io/docs/components/modeler/bpmn/bpmn-coverage/) — pembedaan modeling support dan execution support.
- [Camunda 8.9 Data flow](https://docs.camunda.io/docs/components/modeler/bpmn/data-flow/) — dokumentasi aliran data.

## Metode

Setiap klaim semantik diberi sumber dekat dengan teks. Klaim normatif harus mengarah ke OMG BPMN 2.0.2. Klaim platform menyebut Camunda dan versi. Opini pemodelan diberi label best practice. Jika sumber tidak berhasil diperiksa, status tetap TODO/DRAFTED dan keterbatasan dicatat.

## Status saat ini

Camunda Reference berhasil diambil sebagai teks, tetapi warna dukungan eksekusi tidak tersedia pada ekstraksi. Metadata OMG telah diverifikasi dan tabel event 10.84–10.92 diperiksa dari PDF; review keseluruhan elemen Camunda 8.9 masih berlangsung. Status inventaris tersedia di [Coverage](/appendix/coverage).
