<Callout type="bestpractice">
**Privasi:** Semua pemrosesan terjadi **sepenuhnya di browser Anda**.
File `.bpmn` yang Anda pilih tidak pernah dikirim ke server mana pun.
Situs ini statis dan tidak punya backend.
</Callout>

Pilih kasus yang sedang Anda kerjakan, lalu unggah file `.bpmn` dari komputer Anda.
Alat ini akan memeriksa model Anda terhadap kriteria kasus dan menampilkan hasilnya di samping model referensi.

Hasil pemeriksaan adalah **umpan balik belajar** — bukan nilai, bukan putusan lulus/gagal.
