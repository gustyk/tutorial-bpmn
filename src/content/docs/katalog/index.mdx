## Notasi Tier C

Tier C adalah notasi yang ada di standar OMG BPMN 2.0.2 tetapi berada di luar cakupan tutorial ini karena sangat jarang digunakan di luar konteks teknis yang spesifik.

| ID | Notasi | Arti singkat | Halaman |
|---|---|---|---|
| E09 | Link Event | Pasangan Intermediate Event (Throw + Catch) sebagai konektor visual "goto" — tidak menambahkan semantik eksekusi baru. | [/katalog/link-event/](/katalog/link-event/) |
| E12 | Multiple Event | Event dengan lebih dari satu trigger — catching terpicu oleh salah satu trigger (OR); throwing mengirim semua trigger. | [/katalog/multiple-event/](/katalog/multiple-event/) |
| E13 | Parallel Multiple Event | Seperti Multiple Event tapi untuk catching saja — terpicu hanya setelah *semua* trigger terpenuhi (AND). | [/katalog/parallel-multiple-event/](/katalog/parallel-multiple-event/) |
