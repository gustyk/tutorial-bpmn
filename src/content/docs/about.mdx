## Pendekatan editorial

Klaim semantik dirujuk ke sumber di dekat teks. Penjelasan normatif mengacu pada OMG BPMN 2.0.2, dukungan platform menyebut Camunda dan versinya, dan rekomendasi pemodelan dibedakan sebagai praktik terbaik.

Gambar notasi dibuat ulang secara generik untuk tujuan pendidikan; diagram contoh disediakan sebagai file BPMN agar dapat diperiksa dengan tool BPMN.
