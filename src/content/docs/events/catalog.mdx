Pengelompokan ini menghasilkan 61 entri tabel, dihitung sebagai cakupan visual reference; bukan klaim bahwa hanya ada 61 kombinasi BPMN 2.0.2. Seluruh nama/posisi masih **DRAFTED** sampai diperiksa silang dengan specification dan coverage versi.

## Waspada pada istilah

Tabel Camunda menggunakan kolom trigger/position. Pemahaman final harus mengikuti BPMN 2.0.2. Misalnya, Parallel Multiple adalah catching semantics; penamaan di Camunda overview dan compatibility normative harus diperiksa sebelum menyamakan setiap sel. Link adalah intermediate only; Cancel hanya relevan pada transaction; End event yang bernama “Terminate” harus dibedakan dari None End.

Sumber: [Camunda BPMN Reference](https://camunda.com/bpmn/reference/) dan [OMG BPMN 2.0.2](https://www.omg.org/spec/BPMN/2.0.2/PDF).
