Legenda: `D` = drafted/provisional; `—` = tidak dicantumkan sebagai kombinasi yang didukung dalam inventory awal. Boundary/event-subprocess trigger yang tidak mendukung non-interrupting harus dikeluarkan setelah pemeriksaan normatif.

## Temuan yang masih perlu diperiksa

- Error event subprocess start memang terlihat pada overview Camunda tetapi aturan umum error-catching perlu dibaca tepat pada standar.
- Compensation boundary/event-subprocess start memiliki aturan khusus dan tidak boleh digeneralisasi dari event lain.
- Parallel Multiple bersifat catching-only pada informasi overview; kompatibilitas start/boundary/subprocess harus dibandingkan dengan spesifikasi dan dukungan Camunda.
- Event subprocess dalam prompt awalnya satu kolom; dipisah menjadi interrupting/non-interrupting agar perilaku tidak hilang.
