Legenda: `●` = posisi ditampilkan pada overview Camunda; `—` = posisi tidak ditampilkan pada overview tersebut. Tanda `—` tidak dengan sendirinya menyatakan bahwa kombinasi dilarang oleh BPMN.

## Catatan penggunaan

- Event subprocess dibedakan menjadi interrupting dan non-interrupting karena keduanya memiliki dampak berbeda pada scope induk.
- Event compensation memiliki aturan khusus terkait activity yang dikompensasi dan handler-nya.
- Parallel Multiple menggunakan semantik penangkapan beberapa trigger; lihat BPMN 2.0.2 untuk aturan normatif.
